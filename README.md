## 🌟 Overview & Key Insights

1. **The $60K–$120K Remote Arbitrage System**:
   - US venture-funded startups in San Francisco pay **$250,000–$500,000/year** for on-site software engineers (base salary, employer payroll taxes, healthcare benefits, and equity burn).
   - Hiring high-ownership remote engineers for **$60,000–$120,000/year (~₹50L–₹1 Crore INR)** saves the startup **$180,000+/year per engineer**, directly extending their runway from 7 months to 18 months.
   - **Technical capability is rarely the bottleneck**: 90% of global applicants write adequate code. Rejection occurs due to *execution style*, *lack of autonomous ownership*, and *sub-optimal presentation*.

2. **Execution Over Credentials**:
   - US venture-backed startups ignore CGPA, college tier (IIT/NIT vs Tier-3), and generic certificates.
   - They evaluate candidates on:
     - Autonomous ownership under ambiguity
     - Cost and latency consciousness (e.g. Tiered hybrid routing)
     - Direct, concise asynchronous communication (BLUF format)
     - High-velocity shipping and public failure post-mortems

## 💻 How to Run Locally

### Option 1: Direct Browser Launch
Simply double click or open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Local HTTP Server (Python)
Run the included `start.bat` script or execute:
```bash
python -m http.server 8080 --directory "D:\us-remote-engineering-playbook"
```
Then open: [http://localhost:8080](http://localhost:8080)
